# BMI-Calculator-
BMI Calculator using the concepts of OOPs in Java
📄 BMI Calculator – Java Console Application
👨‍⚕️ Description
This is a simple console-based Java application that calculates the Body Mass Index (BMI) based on user input for weight (kg) and height (m). It classifies the result into standard BMI categories:

Underweight

Normal Weight

Overweight

Obese

The application is built using Object-Oriented Programming (OOP) concepts like encapsulation and abstraction.
